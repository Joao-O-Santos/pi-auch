pi-auch

Another Usage Checker, Horrified. Compact quota visibility for Pi, with escalating pain as your usage runs out.

Description

pi-auch puts OpenAI Codex and GitHub Copilot quota information in Pi's standard footer without sending model probes.

When your usage runs out, the pain escalates.

Install

pi install npm:pi-auch

To try it for one session without installing it:

pi -e npm:pi-auch

Behavior

  • Codex reports both 5-hour and weekly rolling windows.
  • Copilot quota is read passively from normal provider responses.
  • Reactions escalate from nice to ohhh, auch!, and AUCH!!.
